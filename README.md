##  About the Project & Motivation

I built **Coin Rush** duo to my curious about how games actually work, how people make it, if it an easy something to learn or not. So I decided to learn and start my first game, and I tried to apply what I have learnt on this game.

##  Development Journey

- **Concept Design:** Sketched out basic mechanics, movement controls, and target score conditions.
- **Refactoring & Physics:** Fine-tuned collision logic and hitboxes to ensure accurate scoring and game-over triggers.
- **UI/UX Polish:** Designed a retro arcade-style menu and real-time dashboard.


## How to Run / Play

Since this is a lightweight browser-based game, you don't need to install any complex dependencies or servers! You can play it directly in two ways:

1. **Play Online (Recommended):** 
   Head over to the [Itch.io Demo Link](https://donianady.itch.io/pixl) to play it instantly in your browser.

2. **Run Locally:**
   If you want to run or inspect the source code on your machine:
   - **Clone the repository:**
     ```bash
     git clone https://github.com/donianady/coin-rush-game
     ```
   - **Open the game:**
     Navigate to the project folder and simply double-click the `index.html` file to open it in any web browser, or use an extension like **Live Server** in VS Code.
